# Stock Portfolio Tracker

## Description

Stock Portfolio Tracker is a Python-based console application that helps users calculate the total value of their stock investments. Users can enter stock symbols and quantities, view a portfolio summary, and save the results in TXT or CSV format.

## Features

* Display available stocks and their prices
* Add multiple stock holdings
* Calculate total investment value
* Show a detailed portfolio summary
* Save results to a TXT file
* Save results to a CSV file
* User-friendly command-line interface

## Technologies Used

* Python 3
* CSV Module
